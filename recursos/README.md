# Recursos

Material de consulta que acompaña a las once sesiones: no se lee de
corrido, se abre cuando hace falta. La forma cómoda de leerlo es el sitio:
[todos los recursos](https://emirandago.github.io/r-para-ciencia-politica/recursos/index.html).

| Archivo | Qué es | Para qué sirve |
|---|---|---|
| [`glosario.qmd`](glosario.qmd) | Inglés técnico → español, con el estándar propio que fija este laboratorio (`AnalizaR Datos Políticos` no es internamente consistente en su traducción). | Para que una palabra que nadie tradujo la primera vez no sea la razón para dejar de venir. |
| [`errores-comunes.qmd`](errores-comunes.qmd) | Catálogo de los mensajes de error más frecuentes del curso: el texto literal en inglés, su traducción, qué lo causa y el arreglo. | **No es un anexo, es parte del temario.** El curso sostiene que leer un mensaje de error es una destreza que se enseña, no un accidente que se evita; este documento es donde esa destreza se practica fuera de clase. |
| [`para-seguir.qmd`](para-seguir.qmd) | Lo que cada sesión fue dejando pendiente en el camino —una herramienta que no cupo, una pregunta que quedó abierta—, reunido en un solo lugar. | Para decidir hacia dónde seguir después de las once horas, sin tener que adivinarlo. |
| [`acordeon-r.pdf`](acordeon-r.pdf) (fuente: [`acordeon-r.tex`](acordeon-r.tex)) | La sintaxis que más se usa en el curso, en una sola hoja. | Para tener a un lado mientras se programa, sin volver al sitio a buscar cómo se escribía algo. |

El catálogo de errores comunes se referencia desde el bloque "Si algo
falla" de cada `NN_guion.qmd` de [`sesiones/`](../sesiones/): vale la pena
leerlo entero al menos una vez, no solo entrar a buscar un error puntual.
