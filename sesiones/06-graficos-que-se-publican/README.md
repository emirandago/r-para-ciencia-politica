**Pregunta:** ¿Cómo hago una figura de paper?

**Entregable de la hora:** una figura en PDF lista para un trabajo final.

| Archivo | Qué es |
|---|---|
| [`06_guion.qmd`](06_guion.qmd) | La página de esta sesión en el sitio. |
| [`06_slides.tex`](06_slides.tex) | Fuente Beamer de las láminas. |
| [`06_slides.pdf`](06_slides.pdf) | Láminas ya compiladas, para descargar. |
| [`06_script.R`](06_script.R) | Script guía de la hora. Tiene huecos y **no corre de corrido**: se llena en vivo. |
| [`06_script_completo.R`](06_script_completo.R) | Versión resuelta del script, publicada después de la sesión. |
| [`06_ejercicio.R`](06_ejercicio.R) | Ejercicio para llevar. |
| [`06_solucion.R`](06_solucion.R) | Solución comentada del ejercicio. |
