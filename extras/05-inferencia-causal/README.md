# Extra 5 · Primer vistazo a inferencia causal

La forma cómoda de leer esto es la página del curso:
[extra 5 en el sitio](https://emirandago.github.io/r-para-politologos/extras/05-inferencia-causal/05_extra.html).

**Pregunta:** ¿Qué le falta a un antes-y-después para volverse una
comparación honesta?

**Entregable:** tres ideas centrales de inferencia causal, contadas como
aritmética, como dibujo y como historia, no como aparato técnico completo.

| Archivo | Qué es |
|---|---|
| [`05_extra.qmd`](05_extra.qmd) | La página de este módulo en el sitio. |
| [`05_script.R`](05_script.R) | Script guía del módulo. |
| [`05_ejercicio.R`](05_ejercicio.R) | Ejercicio para llevar. |
| [`05_solucion.R`](05_solucion.R) | Solución comentada del ejercicio. |

**Datos:** los ejemplos de diferencias-en-diferencias y de discontinuidad
son simulados o inventados a propósito, marcados como tales en cada bloque
del script. La sección del confusor retoma resultados reales de la
[sesión 9](../../sesiones/09-la-regresion/), calculados sobre
`presidencial_2024_municipio.csv` (ver
[`datos/README.md`](../../datos/README.md), §2).

de la [sesión 9](../../sesiones/09-la-regresion/).
